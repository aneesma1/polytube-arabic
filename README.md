# 🎙️ PolyTube Arabic (بولي تيوب العربية)

> **Distraction-Free Arabic Immersion YouTube Player with Dual Subtitles (العربية ⇄ മലയാളം / English), Root & Pattern Morphology Analysis, and 1-Click Study Exporter.**

[![Deploy PolyTube Arabic to GitHub Pages](https://github.com/aneesma1/polytube-arabic/actions/workflows/deploy.yml/badge.svg)](https://github.com/aneesma1/polytube-arabic/actions/workflows/deploy.yml)

---

## 🌟 Key Features

* **Real Web PWA (Progressive Web App)**: Installable directly on Windows, macOS, Android, and iOS as a standalone app with offline capabilities.
* **Pure Arabic Immersion**: Focused exclusively on Arabic language learning without clutter or unnecessary recommendation distraction.
* **Dual Subtitle Track**: Toggle effortlessly between **മലയാളം (Malayalam)** and **English** translations.
* **Arabic Linguistic Workstation**:
  * **الجذر الثلاثي (Root)**: 3-letter radical extraction (e.g. `ش-ع-ر`, `ن-ط-ق`, `س-ك-ن`).
  * **الوزن والصيغة (Measure / Pattern)**: Morphological measure (e.g. `مَفْعَلَة`, `فُعَّال`, `يَفْعَلُ`).
  * **التشكيل (Vocalization)**: Full Harakat toggle with beautiful Cairo & Amiri Arabic fonts.
  * **الإعراب والمتلازمات (Gemini SLA Insight)**: Collocations, communicative register, and false friend calque warnings.
* **1-Click Study Session Exporter**:
  * 📥 **Markdown (`.md`)**: Formatted vocabulary & dialogue tables for Obsidian/Notion.
  * 🗃️ **Anki Cards (`.csv`)**: Anki-ready flashcard deck with vocalized front and roots/context on back.
  * 🖨️ **Printable Cheat Sheet / PDF**: Browser print preview (`@media print`).

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/aneesma1/polytube-arabic.git
cd polytube-arabic

# Install dependencies
npm install

# Start local dev server
npm run dev:client

# Build production bundle
npm run build
```
